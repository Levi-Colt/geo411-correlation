# geo411-correlation
Conducting Pearson's and Spearman's correlation tests

Overview: This assignment looked at data comparing life expectancy to GDP per capita for various countries. the goal of this assignment was to test for correlation within the data using Pearson's correlation test and spearman's rank correlation test. After the statistics were calculated using R, a hypothesis test was conducted for each correlation test to determine if there was any correlation.

Methods: R, Pearson’s, Spearman's

Key Findings: Both tests successfully identified correlation within the data set, however, the spearman's correlation test identified a higher correlation coefficient amongst the countries in the data set, signifying a strong nonlinear correlation amongst the countries. 

Tools: RStudio

Reflection: Even when a data set exhibits a linear relationship, as was the case with this data set, it is still useful to conduct spearman's rank correlation test because it could be a more accurate measure of correlation within the data.
